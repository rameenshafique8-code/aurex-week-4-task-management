## 1. Project Overview

The Task Management Application is a simple and responsive
web application developed using HTML5, CSS3, and Vanilla JavaScript.

It allows users to organize their daily tasks by adding,
editing, deleting, completing, and filtering tasks.

The application uses browser localStorage to save tasks
so that they remain available after refreshing the page.

## 3. Features Implemented

The application includes the following features:

1. Add new tasks.
2. Edit existing tasks.
3. Delete tasks with confirmation.
4. Mark tasks as completed or pending.
5. Filter tasks by All, Pending, and Completed.
6. Validate task input to prevent empty tasks.
7. Save tasks in browser localStorage.
8. Retrieve saved tasks after page refresh.
9. Update stored tasks when they are edited,
   deleted, or marked as completed.
10. Display total, pending, and completed task counts.
11. Show an empty-state message when no matching tasks exist.
12. Provide a responsive interface for different screen sizes.
